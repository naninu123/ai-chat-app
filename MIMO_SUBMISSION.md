# AI Chat Hub - Multi-Model Conversational Interface

A modern, production-ready AI chat application that brings together the best AI models in one elegant interface. Built with Next.js 15, TypeScript, and Tailwind CSS for optimal performance and user experience.

### Multi-Model AI Support

- **Claude 3.5 Sonnet & Claude 3 Opus** - Anthropic's reasoning powerhouses
- **Gemini 2.0 Flash & Gemini Pro** - Google's latest AI innovations
- **DeepSeek Chat** - Cutting-edge open-source alternative

## 🔧 Quick Start

```bash
# Clone and install
git clone https://github.com/naninu123/ai-chat-app
cd ai-chat-app
npm install

# Configure
echo "OPENROUTER_API_KEY=your-key" > .env.local

# Run
npm run dev
```
